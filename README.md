Практическая работа — Кейс-задача №2
Задание

Написать тестовую программу, которая демонстрирует работу методов базового и производного классов.

Описание программы

В программе реализованы два класса:

Animal — базовый класс.
Dog — производный класс, наследующий свойства и методы класса Animal.

Базовый класс содержит имя животного и методы для вывода имени и демонстрации звука животного.

Производный класс содержит дополнительное поле — породу собаки, а также собственные методы для вывода породы и лая.

Используемые возможности ООП

В программе демонстрируются:

создание классов;
наследование;
модификаторы доступа;
конструкторы;
вызов методов базового класса;
вызов методов производного класса.
Язык программирования

C++

Файл программы

Исходный код программы находится в файле main.cpp.

Результат

Объект производного класса Dog может использовать как собственные методы, так и методы, полученные от базового класса Animal. Таким образом, программа демонстрирует принцип объектно-ориентированного программирования — наследование.
